# Штука 🏃‍♂️☕

Гиперказуальный one-tap раннер. Прототип v0.1.

> Финальная идея: игрок наводит камеру на **любой предмет** (кружку, носок, банан, кота), AI превращает его в бегуна со своими статами и приколами. Здесь — играбельный кор-луп без AI: 6 предзаготовленных персонажей.

## Играть

Открой `index.html` в браузере или задеплой на GitHub Pages.

**Управление:**
- Тап / Space / ↑ — прыжок
- Свайп вниз / ↓ — подкат (в воздухе — быстрое падение)

**Персонажи:**
| Персонаж | Особенность |
|---|---|
| ☕ Кружка | баланс |
| 🧦 Носок | двойной прыжок |
| 🍌 Банан | выше прыжок |
| 🐱 Кот | самый высокий прыжок |
| ⌨️ Клавиатура | тяжелее, ниже прыжок |
| 📚 Книга | баланс |

## Локальный запуск

```bash
# просто открыть файл
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux

# или поднять локальный сервер (нужно для тестов на телефоне)
python3 -m http.server 8000
# и открыть http://<твой-ip>:8000
```

## Деплой на GitHub Pages

1. Создай репозиторий `shtuka` и запушь файлы:
   ```bash
   git init
   git add .
   git commit -m "init: shtuka prototype v0.1"
   git branch -M main
   git remote add origin git@github.com:<username>/shtuka.git
   git push -u origin main
   ```
2. В настройках репо: **Settings → Pages → Source: Deploy from branch → main / (root)**.
3. Через минуту игра доступна по адресу `https://<username>.github.io/shtuka/`.
